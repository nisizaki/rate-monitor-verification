# Paper draft

This English manuscript is a provisional research draft. The experimental section
states a planned protocol and has no controlled empirical results. Author details,
venue-specific formatting, results, and final interpretation remain to be added.

Build with a TeX installation providing pdflatex, BibTeX, and latexmk:

    latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex

The PDF is checked in for review. references.bib is the bibliography source.
